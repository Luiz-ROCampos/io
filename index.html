Start-SE

Plataforma web em Django

Conecta empresários que buscam captação com investidores interessados em novas oportunidades. Cada tipo de usuário vê funções diferentes depois do login.

  • Dois perfis de usuário, empresário e investidor, cada um com cadastro, login e funções próprias.
  • Modelos para empresas, documentos, métricas e propostas de investimento.
  • Regra de negócio: o valuation é calculado automaticamente a partir do valor de captação e do percentual de equity.
  • Upload de pitch, logotipo e documentos, e envio de selfie e RG para verificação de identidade.
  • Painel administrativo do Django para gerenciar usuários e dados.
  • Python
  • Django
  • SQLite
  • HTML e CSS

Portaria

Aplicação desktop de controle de acesso

Sistema para a portaria de uma empresa de ônibus que substitui os relatórios manuais por registros digitais, com login para saber quem fez cada lançamento.

  • Camada de dados própria, com models e managers sobre SQLite usando SQLAlchemy.
  • Registro de entrada e saída de colaboradores, visitantes e terceiros, com horários.
  • Controle de veículos (prefixo e motorista), materiais, manutenção e empréstimo de chaves.
  • Login para saber quem fez cada lançamento.
  • Python
  • PySide6
  • SQLAlchemy
  • SQLite

Study

Aplicação web em Django

Ajuda estudantes a memorizar conteúdo com flashcards. Depois de criar a conta, o estudante monta seus cartões e cria desafios com a quantidade de perguntas que quiser.

  • Cadastro e login de estudantes.
  • Cartões com categoria e nível de dificuldade, com filtros por ambos.
  • Lógica dos desafios: escolha das perguntas por categoria, dificuldade e quantidade, e contagem de acertos, erros e restantes.
  • Dados do relatório exibido em gráfico.
  • Python

  • SQLite

Presentes de casamento

Aplicação web em Python

Organiza a lista de casamento. Os noivos montam a lista de presentes e de convidados, e cada convidado recebe um link único para responder.

  • Link único com token para cada convidado acessar a aplicação.
  • Regra de reserva: ao reservar, o presente é associado ao convidado e sai da lista de disponíveis.
  • Limite de acompanhantes definido por convidado.
  • Dados para o gráfico de presentes reservados e disponíveis.
  • Python
  • Poetry
  • Acesso por token
